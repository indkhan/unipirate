## Contradictions resolved

Selection of a complete trio is an interpretation of the basic evidence requirement; DAAD does not separately state an extra-D exemption. Target requirements must pass on that same trio; independently maximised facts are not a witness.

The old Pakistan attendance-location caveat is removed from candidate data. Explicit national-system identity stays unknown and requires that country's official assessment. Cambridge/Pearson certificates studied in Saudi Arabia or Pakistan remain British international only when explicitly reported as that system. No nationality/residence/visa shortcut supplies it.

Cambridge's PDF resolves the earlier analysis's missing transition evidence for that body alone. Other recognised bodies are covered only for the checker's current explicit WS2026/27, SS2027 and WS2027/28 scope. This is a conservative implementation coverage boundary, NOT an invented policy commencement date. Missing intake and earlier/later uncovered body-specific intakes remain unknown. Cambridge's favourable formula is supported from SS2022; failures there do not evaluate the older four-subject formula.
