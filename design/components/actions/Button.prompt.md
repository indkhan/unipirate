Button — the system's action control; Archivo 600 label, sentence case, 48px tap target by default.

```jsx
<Button variant="primary" fullWidth>Check my eligibility</Button>
<Button variant="secondary">See how it works</Button>
<Button variant="quiet" size="sm">Skip for now</Button>
```

Variants: `primary` (Route Blue — one per screen region), `secondary` (white + hairline), `quiet` (text-only), `danger` (destructive only, never for warnings — those are amber chips, not buttons). Green is never a button color.
